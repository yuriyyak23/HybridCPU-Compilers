# HardwareBridge — краткий отчёт, 27 ноября 2026

**Интеграция не завершена.** Portable HWIR отделён от CircuitWeave. Миграционные fixtures включаются явно с pins Core и SDK. C# capture и независимый Core reader связали сохранённые V2/V4 данные закреплённого Golden, три compiler outputs и 50 generated source rows с PDB. Результат — `CandidateOnly`. Локальный Windows AppContainer fixture прошёл на синтетических входах.

| Защищённый handoff и hosted receipt для согласованных pins остаются открыты. | Владельцы CI подтверждают защиту ref, полномочия dispatch, Windows no-write и положительный receipt Core. |
