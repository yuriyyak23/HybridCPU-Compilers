# HardwareBridge → CircuitWeave

Цель — передать воспроизводимый пакет программных фактов для независимой проверки и аппаратного lowering в CircuitWeave Core. Golden закреплён на `6946ccab9d888f7dae0a4d8e18480f436138acd9`. Путь приложения и основных проверок ориентирован на Windows и .NET/C#.

| Пакет | Связь с Core | Критерий закрытия |
| --- | --- | --- |
| HB-INT-01 | CW-INT-01/02 | Сборка переносимого проекта без Core. Миграционные fixtures по явному opt-in с точными Core/SDK pins. Чистая сборка Companion после восстановления контрактов компилятора. |
| HB-INT-02 | CW-INT-03 | Связать наблюдавшийся Csc, argv/RSP, source/generated bytes, references, analyzer inputs и PE/PDB с точными SHA. Импортировать sealed workspace независимым reader. |
| HB-INT-03 | CW-INT-03/04 | Строгий V1/V2 interchange с source map, MethodDef и замкнутым графом вызовов. Проверить отсутствующие, изменённые и устаревшие байты, роли, порядок, pins и PE/PDB. |
| HB-INT-04 | CW-INT-10/11 | Получить независимые Golden observations с закреплёнными идентичностями. Для stateful scope нужны cycle/retire/memory/trap трассы с reset и replay. |
| HB-INT-05 | CW-INT-06/13 | Core производит typed HWIR и native RTL. Сохранить AddWord regression, проверить каждый заявленный scope и отдельно перечислить символы без elaboration. |
| HB-INT-06 | CW-INT-01/02/03/10 | Подтвердить защищённый handoff, Windows no-write, hosted runs на точных SHA и независимый результат. Для опубликованного scope проверить существующий Studio consumer. |

Актуальные результаты и условия устранения ведутся в [статусе](current/STATUS.md), [реестре доказательств](current/evidence-index.json) и [списке блокеров](current/blockers.md). Обновляйте их после каждого проверенного среза. Записывайте команды, commits, SDK, хэши, артефакты и предел доказанного scope. Для Golden указывайте закреплённые байты либо снимок dirty tree. `Verified` требует независимого результата.

## Сквозные проверки перед закрытием

- Чистые checkout Bridge и Core собираются независимо из переименованных каталогов. Core CLI диагностирует MissingBridge без входного пакета. Проверить wrong pin, циклические ссылки и отсутствие записи в Golden.
- Сопоставить два отдельных снимка Golden: exact clean и captured dirty. Проверить bounded inventory на 1 000+ файлов, разные конфигурации, смену файлов при capture, missing/duplicate/reordered chunks и неизвестные версии.
- Сохранить v1 serialization и совместимость читателей. Для нового envelope сверить SourceSnapshotDigest и отдельный CompanionSourceInputDigest, уникальность полей, роли primary/owned/metadata-only и реальные PE/PDB identities.
- Для каждого переносимого projection сохранить карта «символ → source bytes → HWIR → RTL → independent result». Сравнить старую реализацию и Core на одинаковых наблюдениях Golden. Проверить отрицательные случаи sign, width, CSR и memory events.
- Согласованное изменение wire требует обновления обоих владельцев. Фиксировать пары pins, before/after inventory, команды и фактические native tools. Отсутствующий runtime или инструмент отражается как NotRun либо Blocked с причиной.
