# HardwareBridge

HardwareBridge экспортирует байты исходников, параметры компиляции и программные факты для независимого потребителя CircuitWeave. Core владеет аппаратным lowering, проверкой и публикацией для Studio. Целевая среда — Windows и .NET/C#. Вспомогательные скрипты используются для запуска и воспроизведения проверок.
